# 🖥️ EasyXerox Dedicated Kiosk OS Appliance Setup & Guide

This directory contains the production-grade **Debian Minimal Live Kiosk Appliance** with **Hardware MAC Auto-Pairing**, **CUPS Silent Printing**, and **Dual BIOS (Legacy MBR) + UEFI Boot Support**.

---

## 🔍 Why the Original ISO Failed to Boot in BIOS (Root Cause)

The previous `EasyXerox-Kiosk-Appliance-v1.iso` (generated by `create_bootable_img.py`) was a **dummy 100MB placeholder**:
- It simply wrote `0x55AA` at byte offset 510, followed by plain text metadata and ~99.9MB of zero bytes (`\x00`).
- **What BIOS requires to boot**:
  1. An **ISO 9660** filesystem with an **El Torito Boot Record** pointing to a boot catalog.
  2. An executable bootloader binary in x86 machine code (such as **ISOLINUX** or **GRUB**).
  3. A compiled Linux kernel (`vmlinuz`) and an initial RAM disk (`initrd.img` with `live-boot`).
  4. A root filesystem (`filesystem.squashfs`) containing the OS binaries, systemd, X11, drivers, and runtime services.
- Because none of these existed in the dummy file, the computer's BIOS found no valid boot sector or bootable code and displayed *"No bootable device found"* or *"Operating System not found"*.

---

## 🏗️ Architecture of the Real Bootable Kiosk OS

The new builder compiles a genuine **Debian 12 (Bookworm) Live Hybrid ISO**:

| Layer | Component | Function |
| :--- | :--- | :--- |
| **Bootloader** | **ISOLINUX** (BIOS) + **GRUB EFI** (UEFI) | Dual hybrid boot for both older legacy PCs and modern UEFI motherboards. |
| **Kernel** | `linux-image-amd64` | 64-bit Linux kernel with full hardware driver support (Ethernet, WiFi, USB, Display). |
| **Live System** | `live-boot` + OverlayFS | Boots entire OS into RAM in ~5–8 seconds. Protects SSD/storage against sudden power cuts. |
| **Display Server** | Xorg + Openbox + unclutter | Lightweight X11 session; hides mouse cursor and prevents screen sleeping. |
| **Browser Kiosk** | Chromium Browser | Runs `--kiosk --noerrdialogs --disable-infobars` locked to full-screen. |
| **Print Engine** | CUPS + `printer-driver-all` + `print-service` | Silent background print spooler connected via Socket.IO to central server. |
| **Auto-Pairing** | `kiosk-autostart.sh` | Detects board MAC address, pairs with `https://easyxerox.com/api/machines/identify`, and launches kiosk screen. |

## 🚀 How to Build the Real Bootable ISO

You have **3 methods** to compile the `.iso` file:

### Method 1: Cloud Build via GitHub Actions (Recommended — Zero Local Setup)
*Ideal if you are on a Mac or do not have a Linux machine.*

1. Push your repository to GitHub.
2. Go to your repository on GitHub and click the **Actions** tab.
3. Select **"Build EasyXerox Kiosk Bootable ISO"** on the left.
4. Click **Run workflow** -> **Run workflow**.
5. After ~5–7 minutes, click on the completed run and download **`EasyXerox-Kiosk-Appliance-v1.iso`** from the **Artifacts** section!

---

### Method 2: Build Using Docker (macOS / Windows / Linux)
If you have **Docker Desktop** installed on your computer:

```bash
# 1. Start Docker Desktop
# 2. Run the Docker build script:
cd kiosk-appliance
chmod +x build-with-docker.sh
./build-with-docker.sh
```

The script will compile the complete image and output:
`kiosk-appliance/EasyXerox-Kiosk-Appliance-v1.iso`

---

### Method 3: Build Natively on any Debian / Ubuntu Machine / VPS
If you have an Ubuntu/Debian laptop, PC, or VPS:

```bash
cd kiosk-appliance
sudo chmod +x build-kiosk-iso.sh
sudo ./build-kiosk-iso.sh
```

## 💿 Flashing the ISO to a USB Drive

Once `EasyXerox-Kiosk-Appliance-v1.iso` is built:

1. Insert a USB flash drive (minimum 4 GB).
2. Use one of the following tools:
   - **BalenaEtcher** (Mac / Windows / Linux): Select the ISO, choose your USB drive, and click **Flash!**
   - **Rufus** (Windows):
     - Device: Your USB drive
     - Boot selection: `EasyXerox-Kiosk-Appliance-v1.iso`
     - Partition scheme: **MBR** (for maximum BIOS compatibility)
     - Target system: **BIOS (or UEFI-CSM)**
     - When prompted, choose **Write in ISO Image mode** (or **DD mode**).

---

## ⚙️ BIOS / UEFI Boot Settings Checklist

When booting the kiosk machine from the flashed USB drive:

1. **Power on** the kiosk PC and press the BIOS key (usually `F2`, `F12`, `Del`, or `Esc`).
2. **Boot Order**: Set **USB Storage Device** as the #1 primary boot priority.
3. **Boot Mode**:
   - For **Legacy BIOS**: Enable **CSM (Compatibility Support Module)** or set Boot Mode to **Legacy / Both**.
   - For **UEFI**: Secure Boot should be set to **Disabled** or **Standard** during initial setup.
4. **Fast Boot**: Set to **Disabled** (to allow USB boot detection).
5. **Save & Exit** (`F10`).
6. The machine will display the **EasyXerox Kiosk OS** splash and boot straight into the kiosk UI within seconds!
